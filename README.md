This Network Intrusion Detection System (NIDS), is a signature- and anomaly-based security tool built with Python 3 and Scapy that continuously sniffs live network traffic to detect port scanning, SYN floods, ICMP ping floods, authentication brute-force attempts, and web injection payloads (SQLi and XSS), automatically logs alerts to `nids_alerts.log` and `nids_alerts.csv`, blacklists and drops attacker traffic using Linux `iptables`, displays a real-time summary dashboard, and visualizes attack metrics with Matplotlib using execution commands like `sudo python3 nids.py -i eth0 --block --visualize`.
